UCAPAN ULANG TAHUN — V2

Urutan animasi:
1. Fireworks ramai sejak awal.
2. Partikel fireworks berkumpul membentuk SELAMAT.
3. Partikel berubah membentuk ULANG TAHUN.
4. Partikel berubah membentuk SAYANGGGGKU.
5. Tulisan seperti didekati kamera lalu masuk ke efek warp/galaxy.
6. Di space, planet tersusun dari banyak partikel dengan debu/batu kecil yang mengorbit.
7. Partikel hati muncul dan mengorbit planet.
8. Foto-foto mengorbit planet.
9. Scroll untuk membaca pesan dan melihat gallery.

Cara pakai:
- Foto: masukkan foto1.jpg sampai foto6.jpg ke folder foto/.
- Musik: masukkan about-you.mp3 ke folder music/ jika kamu memiliki hak untuk menggunakannya.
- Edit teks/foto/musik di bagian CONFIG pada script.js.
- Jalankan index.html dengan VS Code + Live Server.
- Untuk dibagikan, upload folder ini ke GitHub Pages.

Catatan musik:
File About You tidak disertakan dalam ZIP. Website hanya menunjuk ke music/about-you.mp3 agar kamu dapat memasukkan file audio yang kamu miliki/berhak gunakan sendiri.
